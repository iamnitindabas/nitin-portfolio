AI-assisted delivery, on the tools that exist

Studio Pro runs a local MCP server; Maia and external agents edit the open model; mxcli applies the same changes as MDL and runs the check.

  • Plan

    Maia Make turns a requirement into entities, pages, microflows and stories.

  • Apply

    The Studio Pro MCP server lets Claude Code or another agent change the model live.

  • Check

    mxcli runs the same changes from the command line, checks the project and starts the app.

SHmcp.sh SHcheck.sh localhost 
# connect an agent
claude mcp add --transport http \
  http://localhost:7782/mcp
# what it can author
mxcli mcp capabilities -p app.mpr \
  --mcp http://localhost/mcp
# apply and check
mxcli exec changes.mdl -p app.mpr \
  --mcp http://localhost/mcp --mcp-check
Studio Pro serves the model on localhost.
